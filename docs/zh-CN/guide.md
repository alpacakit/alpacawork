# 使用方法

读完入门指南之后，每天都会用到的操作。

## 委托

在输入框里用平常的话写下想做的事并发送。在电脑上，Enter 发送，Shift+Enter 换行。

```text
帮我查一下测试失败的原因，并修好。
```

发送的内容会送到负责对接的 AI（协调员）那里。协调员把它变成任务，交给负责的 AI。不必等上一个委托完成，可以接着委托。

对做法的要求，也直接写进去（“做 3 个方案比较一下”“做完后让另一个 AI 检查”）。希望一直这样做的，写进[项目准则](projects.md#项目准则)。

图片和文件，可以用输入框的“+”或直接粘贴附上。

## 界面上没有的事也能委托

更改设置、整理任务、让停住的 AI 继续、更新 alpacawork 等，也都可以在输入框里委托。比起在界面上找操作的位置，这样更快。

```text
把已完成的任务一起归档。
```

## 怎么看列表

任务按状态排列。需要你行动的，是下面两种。

| 分组 | 含义 |
| --- | --- |
| 待验收 | 收到了提问或报告 |
| 需要处理 | AI 的运行停住了。打开即可看到原因 |

“进行中”是 AI 正在推进的，“已完成”是已经结束的。“已完成”等分组起初是收起的，点标题即可展开。其他分组见[用语一览](reference.md#任务的状态)。

## 回答提问

打开任务，会看到提问和回答的选项。

1. 点一个选项。回答会填入输入框。
2. 发送。发送之前不会送达。

选项里没有的回答，点“其他”，用自己的话写。

## 确认报告

阅读报告，打开附带的文件或差异来确认。

- 没问题的话，按界面下方的“完成”（对勾图标）。不按，任务就不会结束。
- 想让它修改时，保持任务打开，把要改的地方写在输入框里发送。

<img src="../images/action-bar.png" alt="打开任务时排在下方的按钮：“Auto-swipe”（自动滑动）、“Change state”（更改状态）和“Done”（完成）" width="338">

按“完成”后，会打开下一个待验收的任务。用于搁置或停止的“更改状态”也在同一处。

## 停住的任务

打开“需要处理”的任务，会看到停住的原因和按钮。

- 按“重试”或“停止”。
- 出现“继续”时，如果可以继续，就按它。
- 没有按钮时，按显示的说明在输入框里下指示。

各种原因的处理方法，见[遇到问题时](troubleshooting.md#任务停住了)。

## 搁置与停止

- 搁置：现在不想决定时使用。打开任务，“更改状态”→“已搁置”→“更新”。正在运行的 AI 不会停下。
- 停止：让工作停下来。“更改状态”→“已停止”→“更新”。下面的任务也会停止。

要从搁置中恢复，同样在“更改状态”里选择要回到的状态。想让已停止的任务再继续时，在输入框里委托。

## 在手机上

把卡片向右滑动是“已完成”或“发送”，向左滑动是“搁置”。
