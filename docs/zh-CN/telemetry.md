# 使用数据

使用数据是对 alpacawork 使用情况的统计（哪些操作用了多少次、版本、操作系统等）。它会发送给开发者，用于改进 alpacawork：了解哪些功能被使用、哪里发生了失败、界面在哪里较慢。

是否发送由你决定。在你作出选择之前不会发送任何内容，即使不发送，alpacawork 也照常工作。选择发送之后，可以随时停止，并删除已发送的数据。

## 发送的内容

在你使用 alpacawork 的每一天，当天的数据会汇总成一份报告，于次日发送。日期按 UTC 计算。没有使用的日子不会发送报告。如果报告未能发送，会在 7 天内重试；超过之后，不再发送并将其删除。

报告包含：

- **操作次数**：界面上的操作（点击发送按钮、搜索等），以及 AI 或终端通过命令所做的更改（创建任务、报告任务状态等），按种类计数。每项计数还带有设备的种类（手机、平板或电脑）及其操作系统、途径（人在界面上操作、AI 或终端；是 AI 时还包括 AI 的种类），以及界面的显示语言和主题
- **运行环境**：alpacawork 的版本、操作系统和 CPU 的类型、Node 的版本
- **AI 的工作**：所用 AI 的种类（`claude`、`codex` 等；你给它们起的名称不会发送）、按推理强度级别统计的次数，以及工作中途失败的次数
- **规模**：项目和任务的数量、任务树的深度、AI 在一个任务上工作的次数、同时进行的 AI 运行数量等
- **显示速度**：从打开界面或任务到内容显示出来所用的时间
- **报告本身的信息**：报告的日期、格式编号，以及这台电脑的 ID

每种操作都有固定的名称。你输入的文字和任务标题绝不会成为名称的一部分。规模、显示速度和失败次数以 `10-19` 这样的大致区间发送。

这台电脑的 ID 是你首次选择发送时生成的随机值，不是根据电脑或用户的任何信息生成的。它用于统计同一台电脑持续使用了多少天，并让你日后可以删除已发送的数据。停止发送后再次开始时，仍使用同一个 ID。

你可以查看实际的报告，内容与将要发送的完全一致（见下文“查看发送内容”）。

## 不发送的内容

- 任务的标题和正文、对话、委托的文字
- 文件和文件夹的名称、仓库的 URL
- 电脑名称和用户名、电子邮件地址
- 错误的文字内容（只统计错误发生的次数）

报告中不包含 IP 地址，接收端也不保留 IP 地址。不过，托管接收端的 Cloudflare 会在传输过程中处理它们（[Cloudflare 的隐私政策](https://www.cloudflare.com/zh-cn/privacypolicy/)）。

## 选择是否发送，以及停止发送

新安装后会打开初始设置界面，你在它的第二步中进行选择。在你选择之前不会发送任何内容；没有作出选择时（例如在初始设置界面出现之前创建的工作区中），不会发送任何内容，界面也不会询问。

之后要更改选择，请使用“设置 → 服务器”末尾的“发送使用数据，帮助改进 alpacawork”开关。关闭即停止发送，打开即开始发送。如果只是想停止，也可以执行 `alpacawork telemetry off`。

停止时，尚未发送的数据会被删除，不再发送。已经发送的数据不会仅因停止而被删除（见下文“删除已发送的数据”）。

如果更新到的版本更改了发送的字段或发送方式，只有此前选择了发送的情况下才会再次询问你。在你回答之前不会发送任何内容。

在某些情况下（例如 alpacawork 在 CI 或容器中运行时），即使你选择了发送，也不会发送任何内容。此时开关无法更改，原因会显示在开关下方。

为服务器设置了环境变量 `ALPACAWORK_TELEMETRY_DISABLED=1` 或 `DO_NOT_TRACK=1` 期间，同样不会发送任何内容。不过，一旦移除该变量，过去 7 天内尚未发送的数据就会被发送。另外，在终端中设置的环境变量不会传给自动启动的服务器。要确保停止发送，请使用界面或命令。

## 查看发送内容

- 界面：“设置 → 服务器”末尾的使用数据开关下方有“查看发送内容”，它显示今天到目前为止的报告（将于明天发送的那份），内容与将要发送的完全一致。只有在发送开启期间才显示内容。那里显示的内容尚未发送，所以如果你停止发送，它就不会被发送。
- 命令：`alpacawork telemetry show` 显示今天到目前为止的数据、此前几天尚未发送的报告、已发送报告在你这里的副本，以及可能发送的名称和值的列表。即使在你选择发送之前，也会显示这份列表。

两者显示的都是 JSON。`alpacawork telemetry` 的各个命令只有由人在这台电脑的终端中输入时才有效。

## 删除已发送的数据

- 界面：使用“设置 → 服务器”末尾的使用数据开关下方的“删除已发送的数据”。即使已经停止发送，也可以使用。电脑上尚未发送的数据也会一并删除。
- 删除页面：在 <https://alpacakit-telemetry.alpacakit.workers.dev/delete>（英文页面）中输入这台电脑的 ID。无法打开 alpacawork 的界面时，或要删除来自一台已不再使用的电脑的数据时，请使用此页面。ID 可以在“删除已发送的数据”打开的窗口中找到，也可以在 `alpacawork telemetry status` 的 `id` 中找到。

删除操作会移除用该 ID 发送的报告，以及该 ID 的记录（首次和最后一次发送的日期）。不区分电脑的汇总数据（例如每天的操作次数或电脑数量）中的数据无法移除。

删除并不会停止发送。如果继续发送，新的数据会用同一个 ID 发送。删除页面不会删除电脑上的数据，所以如果那台电脑仍在发送，请先停止发送，再删除。否则，尚未发送的数据之后仍会被发送。

## 发送到哪里、谁能看到、保留多久

- 发送到哪里：开发者在 Cloudflare Workers 上搭建的接收端（`https://alpacakit-telemetry.alpacakit.workers.dev/v1/report`）。
- 谁能看到：只有 alpacawork 的开发者。汇总数据的仪表盘需要登录，并按原样显示各项数量，包括数量很小的项。对外公布数量时，会剔除不足 10 台电脑的分组，并注明这些数量仅来自选择了发送的电脑。
- 保留多久：每份报告连同其 ID 保留约 3 个月，然后删除。ID 的记录在其最后一次发送之日起约 3 个月后删除。不含 ID 的汇总数据无限期保留，无法从中追溯到各台电脑的报告。
