# 使用数据

使用数据是对 alpacawork 使用情况的统计（哪些操作用了多少次、版本、操作系统等）。它会发送给开发者，用于了解常用的功能、发生失败的地方和界面慢的地方，以改进 alpacawork。

是否发送由你决定。在你作出选择之前不会发送任何内容，不发送也能照常使用。选择发送之后，也可以随时停止，并删除已发送的数据。

## 发送的内容

在使用了 alpacawork 的每一天，都会把当天的数据汇总成 1 份报告，在第二天发送。日期按 UTC 划分（北京时间上午 8 点）。没有使用的日子不发送报告。发送失败时，会在 7 天内重试，超过 7 天的部分不再发送，直接删除。

报告中包含以下内容。

- **操作次数**：界面上的操作（按了发送按钮、进行了搜索等），以及通过 AI 或终端命令进行的更改（创建任务、报告状态等），按种类统计的次数。同时还会发送进行操作的设备类型（手机、平板、电脑）和操作系统、途径（人在界面上操作、来自 AI、来自终端；来自 AI 时，还包括那个 AI 的种类），以及界面的显示语言和主题
- **运行环境**：alpacawork 的版本、操作系统和 CPU 的种类、Node 的版本
- **AI 的工作**：使用的 AI 的种类（`claude`、`codex` 等。你自己起的名称不会发送）、各推理强度的次数、中途失败的次数
- **规模**：项目和任务的数量、任务层级的深度、一个任务中 AI 工作的次数、同时运行的 AI 工作的数量等
- **显示速度**：从打开界面或任务到内容显示出来的时间
- **报告本身的信息**：报告的日期、格式编号、这台电脑的 ID

操作的种类只有预先定好的名称。不会包含你输入的文字或任务标题。规模、显示速度和失败次数，以 `10-19` 这样的大致范围发送。

这台电脑的 ID，是你第一次选择发送时生成的随机值，不由电脑或用户的信息生成。它用于统计同一台电脑连续使用了多少天，并让你之后能删除已发送的数据。停止发送后再重新开始，也使用同一个 ID。

实际的报告，可以按发送时的原样查看（见下面的“查看发送内容”）。

## 不发送的内容

- 任务的标题和正文、对话、委托的文字
- 文件和文件夹的名称、仓库的 URL
- 电脑和用户的名称、电子邮件地址
- 错误信息的文字（只统计次数）

报告中不包含 IP 地址，接收端也不保留。不过，在传输过程中，托管接收端的 Cloudflare 会处理它（[Cloudflare 的隐私政策](https://www.cloudflare.com/zh-cn/privacypolicy/)）。

## 选择是否发送与停止发送

在新安装后打开的初始设置界面的第 2 步中选择。在你选择之前不会发送任何内容。没有选择时（例如在初始设置界面出现之前创建的工作区）也不会发送，界面也不会来问你。

之后要更改时，使用“设置 → 通用”中的“发送使用数据，帮助改进 alpacawork”开关。关掉即停止，打开即开始。只是停止的话，也可以使用命令 `alpacawork telemetry off`。

停止后，尚未发送的部分不再发送，直接删除。已经发送的部分，仅仅停止并不会删除（见下面的“删除已发送的数据”）。

升级到改变了发送项目的种类或发送方式的版本时，只会在之前选择了发送的电脑上再问一次。在你回答之前不会发送。

在 CI 或容器中运行等情况下，即使选择了发送，也可能不发送。这时开关无法操作，原因会显示在开关下方。

服务器设置了环境变量 `ALPACAWORK_TELEMETRY_DISABLED=1` 或 `DO_NOT_TRACK=1` 期间，也不会发送。不过，去掉它们后，过去 7 天中尚未发送的部分会被发送。另外，在终端里设置的环境变量，不会传给自动启动的服务器。要确保停止，请使用界面或命令。

## 查看发送内容

- 界面：在“设置 → 通用”中的使用数据开关下方，用“查看发送内容”可以按发送时的原样，查看今天到目前为止的报告（第二天发送的那份）。只在发送开启期间显示。这里显示的部分还没有发送，停止发送就不会被发送。
- 命令：用 `alpacawork telemetry show` 可以查看今天到目前为止的部分、之前尚未发送的报告、已发送报告的副本，以及可能发送的名称和值的一览。这个一览在选择发送之前也能查看。

两者都以 JSON 格式显示。`alpacawork telemetry` 命令只能由人在这台电脑的终端中输入使用。

## 删除已发送的数据

- 界面：使用“设置 → 通用”中的使用数据开关下方的“删除已发送的数据”。停止发送后也能删除。电脑上尚未发送的部分也会一并删除。
- 删除页面：在 <https://alpacakit-telemetry.alpacakit.workers.dev/delete>（英文页面）中输入这台电脑的 ID。无法打开 alpacawork 的界面时，或要删除已不再使用的电脑的数据时使用。ID 可以在“删除已发送的数据”打开的界面中找到，也可以在 `alpacawork telemetry status` 的 `id` 中找到。

会被删除的，是用这个 ID 发送的报告，以及这个 ID 的记录（第一次和最后一次发送的日期）。不区分是哪台电脑的统计（每天的操作次数、设备数量等）中的部分，无法删除。

删除并不会停止发送。继续发送的话，今后的数据会以同一个 ID 发送。删除页面不会删除电脑上的数据，所以如果那台电脑仍在发送，请先停止发送再删除。不停止的话，尚未发送的部分之后还会被发送。

## 发送到哪里、谁能看、保存多久

- 发送到哪里：开发者在 Cloudflare Workers 上搭建的接收端（`https://alpacakit-telemetry.alpacakit.workers.dev/v1/report`）。
- 谁能看：只有 alpacawork 的开发者。统计界面受登录保护，较小的数字也照原样显示。对外公开数字时，会去掉不足 10 台设备的分组，并注明这只是选择了发送的电脑的数字。
- 保存多久：每份报告带着 ID 保存约 3 个月，之后删除。ID 的记录，从最后一次发送起约 3 个月后删除。不含 ID 的统计不设期限保存。无法从统计还原出每台设备的报告。
