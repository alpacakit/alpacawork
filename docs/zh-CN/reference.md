# 用语与命令一览

用来查界面上见到的用语含义的页面。设置项的含义，可以在输入框里问 AI。

## 角色的名称

| 用语 | 含义 |
| --- | --- |
| 你 | 使用界面的人 |
| 协调员 | 负责对接的 AI。从输入框发送的内容，全都送到这里 |
| 负责人 | 负责一个任务的 AI |
| 成员 | 负责人叫来帮忙的 AI |
| 父任务、子任务 | 上一层的任务、拆分出来的下层任务 |

## 任务的状态

| 用语 | 含义 |
| --- | --- |
| 进行中 | AI 正在工作 |
| 待验收 | 轮到你了。收到了提问或报告。等你确认报告的任务，其状态也显示为这个词 |
| 需要处理 | 轮到你了。AI 的运行停住了 |
| 等待中 | 在等其他回复。还没轮到你 |
| 未开始 | 还没有开始 |
| 已搁置 | 你推后处理的任务 |
| 已完成 | 已经结束的任务。停止的任务也归在这里 |
| 出错 | 停住了。列表中归在“需要处理”下 |

## 停止原因的用语

显示在“需要处理”的行上。要做什么，见[遇到问题时](troubleshooting.md#任务停住了)。

| 用语 | 含义 |
| --- | --- |
| 失败 | 运行失败了，或没有报告就结束了 |
| 已达上限 | AI 之间自动往来的次数达到了上限 |
| 送达未确认 | 无法确认是否已送到 AI。请在“历史”中查看进展 |
| 被拒绝 | 后续的委托没有被接受 |
| 无启动配置 | 设置中没有这个 AI 智能体，或它没有启用 |
| 无法启动 | 无法让负责的 AI 开始工作 |
| 无法继续 | 无法接着之前的对话继续。请下指示“在新的对话中继续” |
| 层级上限、委托数上限 | 子任务的层数，或一次运行中的委托数达到了上限 |
| 已超时 | 超过了一次运行的时间上限 |
| 提前结束、未能启动 | AI 智能体的程序停止了，或无法启动 |

## 键盘

“⌘/Ctrl”在 Mac 上是 ⌘，在其他系统上是 Ctrl。

| 键 | 作用 |
| --- | --- |
| `/` | 移到输入框 |
| ⌘/Ctrl+Enter | 在任何设备上发送（在电脑上只按 Enter 也会发送） |
| 在输入框中按 `#` | 选择任务或项目并附上 |
| ⌘/Ctrl+K | 搜索 |
| ⌘/Ctrl+, | 打开设置 |
| Esc | 离开输入框，关闭打开的任务 |
| H | 搁置打开的任务 |

## 命令

在终端（Windows 上是 Ubuntu 中）执行。除此之外的命令是供 AI 使用的。

| 命令 | 作用 |
| --- | --- |
| `alpacawork setup` | 安装 |
| `alpacawork setup --yes --port <端口号>` | 更改界面 URL 的端口 |
| `alpacawork setup --yes --public-host <名称>` | 设置从其他设备打开时使用的 `https://` 名称 |
| `alpacawork open` | 在浏览器中打开界面 |
| `alpacawork start`、`stop`、`restart` | 启动、停止、重启 |
| `alpacawork status` | 显示是否在运行，以及界面的 URL |
| `alpacawork workspace url` | 显示界面的 URL |
| `alpacawork deploy npm:alpacawork` | 更新到最新版本 |
| `alpacawork uninstall` | 从这台电脑上移除。数据存放位置会保留 |
| `alpacawork --version` | 显示已安装的版本 |
| `alpacawork telemetry off` | 停止发送使用数据 |
