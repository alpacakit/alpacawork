# alpacawork 文档

alpacawork 是把工作交给电脑上的 Claude Code 或 Codex 的工具。在输入框里写下委托，AI 会把它变成任务并推进；只有需要你判断时，任务才会出现在“待验收”中。

第一次使用，请从下面的“入门指南”读起。大约 15 分钟，就能走完发出第一个委托并确认结果的全过程。

## 页面

- [入门指南](getting-started.md) — 从安装、发出一个委托到确认结果
- [使用方法](guide.md) — 委托、回答提问、确认报告、搁置与停止
- [按你的工作调整](projects.md) — 已有的仓库、项目准则、要使用的 AI 和模型
- [手机与通知](remote.md)
- [遇到问题时](troubleshooting.md) — 任务停住了、界面打不开
- [重新打开、停止、更新](manage.md) — URL、更新、卸载、数据存放位置
- [从 Claude Code 或 Codex 使用](chat.md) — 在对话中委托、确认任务，请求更新或重启
- [用语与命令一览](reference.md)
- [alpacawork 的设计理念](concept.md)
- [使用数据](telemetry.md)

用法上有不明白的地方，可以在界面的输入框里问 AI。更改设置，大多也只要说一声，AI 就会替你完成。

被要求安装、更新或连接 alpacawork 时，请完整阅读并遵循[安装手册](../../skills/alpacawork/references/setup.md)，运行不正常时请完整阅读并遵循 [Troubleshooting](../../skills/alpacawork/references/troubleshoot.md)，不要只读摘要。
