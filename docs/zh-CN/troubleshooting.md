# 遇到问题时

如果能打开界面，最快的办法是在输入框里问 AI（“预约表单的任务为什么没有进展？”）。AI 能读到处理方法的手册。

请不要自己删除数据存放位置（`~/alpacawork`）或记录文件来重新开始。

## 任务停住了

“需要处理”的任务，表示 AI 的运行停住了。打开后，标题下方会显示原因。

- “失败”：按“重试”或“停止”。想让它换个做法时，不要按按钮，改为在输入框里写下并发送。如果原因是用量上限或模型繁忙，请在上限恢复后按“重试”，或在输入框里委托“换个模型重试”。上限恢复后也不会自动继续。
- “已达上限”：AI 之间自动往来的次数达到了规定值（起初为 20 次）。如果可以继续，按“继续”。
- 没有按钮的原因（“送达未确认”“无启动配置”等）：阅读显示的文字，在输入框里下“继续”之类的指示。含义见[停止原因的用语](reference.md#停止原因的用语)。

## 发送了却没有进展

输入框上方会显示发送状态。点它会打开与负责对接的 AI 的对话。

- “正在发送…”“排队中”“正在处理…”等：请等待。
- “未发送（原因）”：读原因并处理后，再发送一次。
- “无法确认是否送达”：打开对话，按“重新发送”或“撤回”。
- “未能收到回复”：按“重新发送”。附件不会重新发送，所以带附件的委托请重新写好再发送。如果是用量上限，请等上限恢复，或换一个模型后再发送。
- “无法启动协调员。”：请看下面的“AI 智能体无法使用”。

## 不知道任务是否在运行

- “进行中”那一行的时间在增加，就说明 AI 在运行。
- “最后一次输出已较久”：不一定是停住了。请等一会儿，如果还没有变化，就在输入框里问。
- 行上的“排队中”：已达到同时运行数量的上限，正在等空位。
- 行上的“等待 T12”：在等 T12 完成。如果 T12 停住了，先处理 T12。

## 重启或休眠了电脑

登录电脑后，alpacawork 会自动启动，任务保持原样。重启前正在进行的工作会停止。移到“需要处理”的任务，请打开并按“重试”。不会自动继续。

休眠期间工作不会推进。笔记本电脑合上盖子就会停止。

## 界面打不开

显示“无法访问此网站”时，表示 alpacawork 没有在运行。启动它，然后重新加载页面。

- 在终端执行 `alpacawork start`。
- Windows：从开始菜单打开 Ubuntu，alpacawork 也会随之启动。请让这个窗口保持打开。如果仍然打不开，就在这个窗口里执行 `alpacawork start`。

忘记 URL 时，请看[重新打开界面](manage.md#重新打开界面)。

从其他设备无法打开 `http://127.0.0.1:...`。请使用[在手机上使用](remote.md#在手机上使用)或[通过 SSH 连接的电脑](manage.md#安装在通过-ssh-连接的电脑上时)中的 `https://` URL。

更新 Node.js 之后无法启动时，执行 `alpacawork setup` 并按 Enter。

## 出现“离线”等提示

- “你已离线”“正在等待 alpacawork 响应。”：确认 alpacawork 是否在运行（上面的“界面打不开”）。连上后会自动恢复。
- “alpacawork 的版本已变化。”：按“重新加载”。
- “这台主机处于高负载”：用“查看”确认占用资源的工作，并调小同时运行的数量。

## AI 智能体无法使用

“设置（齿轮）→ 服务器”的“智能体”中会显示状态。

- “需要登录”：在终端执行登录命令。

  | AI 智能体 | 命令 |
  | --- | --- |
  | Claude Code | `claude auth login` |
  | Codex | `codex login` |
  | GitHub Copilot | `gh auth login` |

- “未找到”：没安装的话就安装。已经安装的话，在卡片的“可执行文件”中指定位置。
- “没有已启用的智能体”：启用要使用的 AI。

处理好之后，停住的任务用“重试”继续。

## 安装中途停住

处理好显示的原因后，再执行一次同样的命令，就会从中断处继续。

- `requires Node >=24.16.0`：装好 Node.js 24 后再执行。
- `command not found`：重新打开终端。
- 无法写入的错误、`does not run as root`：不要加 `sudo`，用通过 nvm 等安装的 Node.js 来执行。
- `User service manager is unavailable`：如果是 WSL2，请[启用 systemd](manage.md#在-windows-上使用)。

其他消息，请把显示的文字原样贴给 AI 商量。

## 找 AI 商量时要提供的内容

在终端启动 Claude Code 或 Codex，调用 alpacawork 技能（`/alpacawork` 或 `$alpacawork`）后，提供以下内容。

- 显示的文字原样照贴。任务编号（如 T12）
- 做了什么之后发生的
- `alpacawork workspace url` 的输出

bug 请报告到 [Issues](https://github.com/alpacakit/alpacawork/issues)。安全漏洞请不要写在 Issue 里，按 [SECURITY.md](https://github.com/alpacakit/alpacawork/blob/main/SECURITY.md) 的步骤告知。
