# 言葉とコマンドの一覧

画面で見かけた言葉の意味を引くページです。設定の項目は、画面の各項目の下に説明が出ています。

## 役の名前

| 言葉 | 意味 |
| --- | --- |
| あなた | 画面を使っている人 |
| コーディネーター | 窓口の AI。入力欄から送ったものは、すべてここに届きます |
| 責任者 | 1つのタスクを受け持つ AI |
| 作業者 | 責任者が手伝いに呼ぶ AI |
| 親、子 | 1つ上のタスク、分けてできた下のタスク |

## タスクの状態

| 言葉 | 意味 |
| --- | --- |
| 作業中 | AI が作業しています |
| 確認待ち | あなたの番。質問か報告が届いています |
| 対応待ち | あなたの番。AI の実行が止まっています |
| 待機中 | ほかの返事を待っています。あなたの番ではありません |
| 未着手 | まだ始まっていません |
| 保留 | あなたが後回しにしたもの |
| 完了 | 終わったもの。中止したタスクも入ります |
| レビュー待ち | 報告の確認を待っています。一覧では「確認待ち」に並びます |
| エラー | 止まっています。一覧では「対応待ち」に並びます |

## 止まった理由の言葉

「対応待ち」の行に出ます。することは [困ったとき](troubleshooting.md#タスクが止まった) にあります。

| 言葉 | 意味 |
| --- | --- |
| 失敗 | 実行が失敗したか、報告せずに終わりました |
| 上限停止 | AI どうしの自動のやり取りが、上限の回数に達しました |
| 受領不明 | AI に届いたかを確かめられません。「履歴」で進み具合を見ます |
| 受付拒否 | 続きの依頼が受け付けられませんでした |
| 設定なし | その AI エージェントが設定に無いか、有効でありません |
| 開始不可 | 担当の AI を始められません |
| 再開不可 | 前の会話を続けられません。「新しい会話で続けて」と指示します |
| 深さ上限、依頼上限 | 子のタスクの段数か、1回の実行の依頼の数が上限に達しました |
| 時間切れ | 1回の実行の時間の上限を過ぎました |
| 途中で終了、起動できず | AI エージェントのプログラムが止まったか、起動できませんでした |

## キーボード

「⌘/Ctrl」は、Mac では ⌘、ほかでは Ctrl です。

| キー | 働き |
| --- | --- |
| `/` | 入力欄へ移る |
| ⌘/Ctrl+Enter | 送信する |
| 入力欄で `#` | タスクやプロジェクトを選んで添える |
| ⌘/Ctrl+K | 検索 |
| ⌘/Ctrl+, | 設定を開く |
| Esc | 入力欄から出る、開いたタスクを閉じる |
| H | 開いているタスクを保留にする |

## コマンド

ターミナル（Windows では Ubuntu の中）で実行します。このほかのコマンドは AI が使うものです。

| コマンド | 働き |
| --- | --- |
| `alpacawork setup` | インストールする |
| `alpacawork setup --yes --port <番号>` | 画面の URL のポートを変える |
| `alpacawork setup --yes --public-host <名前>` | ほかの端末から開く `https://` の名前を設定する |
| `alpacawork workspace url` | 画面の URL を表示する |
| `alpacawork deploy npm:alpacawork` | 最新の版へ更新する |
| `alpacawork uninstall` | この PC から外す。データの置き場は残る |
| `alpacawork --version` | 入っている版を表示する |
| `alpacawork telemetry off` | 使用統計データの送信を止める |
