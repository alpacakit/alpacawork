## 画面の言葉

### 役の名前

タスクを開いたときの「履歴」などで、だれからだれへのものかを示す言葉です（[登場するもの](concept.md#登場するもの)）。

| 言葉 | 意味 |
| --- | --- |
| あなた | 画面を使っている人です |
| コーディネーター | あなたの窓口になる AI です。入力欄から送ったものは、すべてここに届きます |
| 責任者 | 1つのタスクの結果に責任を持つ AI です |
| 作業者 | 責任者が手伝いに呼ぶ AI です |
| 親 | 開いているタスクの、1つ上のタスクです |
| 子 | 開いているタスクを分けてできた、下のタスクです |

### タスクの状態

一覧は、タスクを次の7つの区分に分けて、この順に並べます。タスクが無い区分は出ません。「待機中」「保留」「完了」は初めは閉じていて、見出しを押すと開きます。読み方は [区分](guide.md#区分) にあります。

| 区分 | 意味 | あなたの番 |
| --- | --- | --- |
| 作業中 | AI が、そのタスクか下のタスクで作業しています | いいえ |
| 対応待ち | AI の実行が失敗した、などの理由で止まっています（[止まった理由の言葉](#止まった理由の言葉)） | はい |
| 確認待ち | 質問か、報告の確認です | はい |
| 待機中 | ほかの返事などを待っています。動いている AI は無く、あなたの番でもありません | いいえ |
| 未着手 | まだ始まっていません | いいえ |
| 保留 | あなたが後回しにしたものです。質問や報告があっても、ここに並びます | いいえ |
| 完了 | 終わったものです。中止したタスクも、ここに並びます | いいえ |

検索結果、タスクツリー、タスクのカードには、区分の名前ではなく、タスクごとの表示の言葉が出ます。区分の名前と違うものは、次のとおりです。「状態を変更」で選べるのは、このうち状態の言葉（「完了」「保留」「中止」など）です。

| 言葉 | 意味 | 一覧での区分 |
| --- | --- | --- |
| レビュー待ち | 報告が出ていて、確認を待っています。通知の設定の「タスクがレビュー待ちになったとき」も、この状態のことです。スマートフォンの一覧の行には「レビュー」と出ます | 確認待ち |
| 質問 | AI が、あなたに質問しています。状態ではなく、あなたへの問いがあることを示す表示です | 確認待ち |
| エラー | 止まっています | 対応待ち |
| 中止 | 作業をやめたタスクです（[作業を止める](guide.md#作業を止める)） | 完了 |

### 履歴に出る種類

タスクを開いたときの「履歴」の、行ごとの先頭に出る言葉です。

| 言葉 | 意味 |
| --- | --- |
| 質問 | AI からの質問です |
| 回答 | 質問への答えです |
| 報告 | AI からの報告です |
| 完了 | タスクを完了にした報告です |
| 確認 | 報告を確かめて、完了にした記録です |
| 依頼 | AI に送った指示です |
| 発言、返事 | 「発言」は、このタスクについてあなたがコーディネーターに送った言葉です。「返事」は、それへのコーディネーターの返事です |
| 停止 | AI の実行が失敗したか、報告せずに終わったか、止められました。理由が続けて出ます |
| 緊急 | AI が、頼んだ側にすぐ読んでほしい理由を付けて出した記録や報告です |
| 変更 | タスクの変更の記録です（題名、移動、責任者の交代、保留とその解除、本文の更新など） |
| 記録 | 状態を変えない、途中の記録です |
| 取り下げ | AI が、回答を待たずに質問を取り下げました |
| 失効 | 宛先が変わったか、タスクが中止になって、質問が無効になりました |

### 止まった理由の言葉

「対応待ち」の行に出る言葉です。行にポインタを置くか、タスクを開くと、理由の文が出ます。「起動できず」から下は、AI の実行が終わった理由を表します。理由ごとにすることは、[タスクが「対応待ち」にある](troubleshooting.md#タスクが対応待ちにある) にあります。

| 言葉 | 意味 |
| --- | --- |
| 失敗 | AI の実行が失敗したか、報告せずに終わりました |
| 上限停止 | 人の指示なしに続いた自動のやり取りが、上限の回数に達して止まりました（[サーバー](#サーバー) の「1つのタスクで1エージェントへ自動で届く依頼の上限」） |
| 受領不明 | AI に返事が届いたかを確認できません |
| 受付拒否 | 続きの依頼が受け付けられませんでした |
| 設定なし | AI エージェントの起動の設定がありません |
| 深さ上限 | 依頼が、深さの上限に達しました（「依頼をたどれる深さ」） |
| 依頼上限 | 1回の実行の依頼の数が、上限に達しました（「1回の実行が出せる依頼の数」） |
| 開始不可 | 責任者への依頼を始められません |
| 再開不可 | AI の前の会話を続けられません |
| 起動できず | AI エージェントを起動できませんでした |
| 途中で終了 | AI エージェントのプログラムが、途中で終わりました |
| 報告せず終了 | 報告も質問も依頼も無いまま、作業が終わりました |
| 時間切れ | 決めた時間（「1回の実行の上限（分）」）を過ぎたので止めました |
| 中断 | 止める操作で終わりました |
| 出力を読めず | AI エージェントの出力を読めませんでした |
| 会話が使用中 | 同じ会話が別の作業で使われていたので、始められませんでした |
| 実行を確認できず | 作業がどうなったか、確認できません |
| 理由不明 | 終わった理由の記録がありません |

## 設定の一覧

設定は、上のバーの右端にある歯車（「設定」）で開きます。タブは「自分」「サーバー」「アプリ・スマホ」「端末の状態」「プロジェクト」の順に並びます。

- 「自分」は、変えるとすぐ保存されます。値はこのサーバーに1組で、つないでいるすべての端末で同じになります。
- 「サーバー」は、「保存」を押すまで保存されません。「変更を破棄」で元に戻ります。保存のあとの再起動は要りません。
- たいていの設定は、入力欄でコーディネーターに頼んでも変えられます（[画面に無い操作を頼む](guide.md#画面に無い操作を頼む)）。
- 新しい版があるときなどは、タブの上に更新の状態が出ます（[更新する](manage.md#更新する)）。

### 自分

上の3つは「表示」、その下は「通知」の項目です。通知の項目の選択は、登録したすべての端末に適用されます。通知の手順は [通知](remote.md#通知) に、知らせの選び方は [知らせの種類を選ぶ](remote.md#知らせの種類を選ぶ) にあります。

| 項目 | 意味 | 初めの値 |
| --- | --- | --- |
| 「表示言語」 | 画面の言語です。English、日本語、简体中文、Español、Português (Brasil) から選びます。AI の返事の言語は別です（[画面に無い設定](#画面に無い設定)） | 最初に画面を開いたブラウザの言語（`--lang` を付けてインストールしたときは、その言語）。選べない言語のときは English |
| 「テーマ」 | 「システム」「明るい」「暗い」から選びます。「システム」は端末の外観に合わせます | 「システム」 |
| 「アップデート前に確認する」 | 更新の前に確認を出します。確認で「次回もこの確認を表示する」を外したあとにだけ、この項目が出ます | オン |
| 「操作がないと離席に」 | 画面を開いたまま操作をやめてから、通知を送り始めるまでの時間です（[届くタイミング](remote.md#届くタイミング)） | 「5分後」 |
| 「毎日止める時間帯」 | 毎日、決めた時間帯は通知を送りません。明けたら、まだ待っている知らせを1通で送ります（[通知を止める](remote.md#通知を止める)） | オフ。時刻は 22:00〜08:00 |
| 「タスクがレビュー待ちになったとき」 | 報告が届いて、確認待ちになったときに知らせます | オン |
| 「タスクがあなたに質問したとき」 | 質問が届いたときに知らせます | オン |
| 「対応が要る返事」 | タスクが止まって、対応待ちになったときに知らせます | オン |
| 「タスクが完了したとき」 | タスクが完了になったときに知らせます | オフ |
| 「タスクが中止になったとき」 | タスクが中止になったときに知らせます | オン |
| 「端末の負荷が厳しいとき」 | PC の CPU、メモリ、ディスクの余裕が少なくなったときに知らせます（[端末の状態](#端末の状態)） | オン |
| 「プッシュ通知」の「この端末で受け取る」 | この端末で通知を受け取る登録です。端末ごとに押します（[この端末で受け取る](remote.md#この端末で受け取る)）。「登録した端末」から外せます（[登録した端末を外す](remote.md#登録した端末を外す)） | 登録なし |

### サーバー

「エージェント」は、初めは閉じています。開くと、AI エージェントごとのカードが並びます。手順は [エージェントの設定を変える](projects.md#エージェントの設定を変える) にあります。閉じたカードに「サインインしていません。」や「実行ファイルが見つかりません:」と出るときは、[AI エージェントが使えない](troubleshooting.md#ai-エージェントが使えない) を見てください。

| 項目 | 意味 | 初めの値 |
| --- | --- | --- |
| 「有効」「無効」 | 無効にすると、新しい依頼を受けなくなります。受け付け済みの作業は続きます（[有効にする・デフォルトを決める](projects.md#有効にするデフォルトを決める)） | セットアップで選んだとおり |
| 「デフォルト」「デフォルトに設定」 | タスクを任せるとき、特に選ばなければ「デフォルト」の印のエージェントになります | セットアップで選んだエージェント |
| 「実行ファイル」 | エージェントのプログラムの場所です。「自動」は、サーバーが最初に見つけたものを使います。「ほかの場所」で場所を指定します（[実行ファイルの場所を指定する](projects.md#実行ファイルの場所を指定する)） | 「自動」 |
| 「依頼のときに選べる値」 | モデルやエフォートなど、依頼のときに選べる値です。「値」はカンマで区切り、先頭の値が最初に選ばれます（[モデルやエフォートを足す](projects.md#モデルやエフォートを足す)） | エージェントの種類ごとの値（「初期値」の印） |
| 「起動オプション」 | エージェントを起動するときの指定です。「高度な設定で編集」で変えると、動作保証の対象外になります | 種類ごとの標準 |
| 「追加で渡す環境変数」 | エージェントに渡す環境変数の名前です。値は環境変数ファイルに書きます（[API キーを渡す](projects.md#api-キーを渡す)） | 種類ごとの標準 |
| 「＋ エージェントを追加」 | 「種類」と「名前」を決めて、エージェントの設定を足します | — |

「高度なオプション」も、初めは閉じています。開くと「実行の上限」が出ます。変更は、次に受け付ける依頼と次の起動から効きます（[同時に動かす数と実行の上限](projects.md#同時に動かす数と実行の上限)）。

| 項目 | 意味 | 初めの値 |
| --- | --- | --- |
| 「同時に動かす数」 | 同時に作業する AI の数の上限です。すべてのプロジェクトを合わせて数え、超えた分は順番を待ちます。画面のコーディネーターは数えません | 8 |
| 「1回の実行の上限（分）」 | AI の1回の実行にかけられる時間です。超えると止めて、失敗にします。0 は上限なしです | 0 |
| 「依頼をたどれる深さ」 | 親から子へ、依頼を重ねられる段の数です | 8 |
| 「1回の実行が出せる依頼の数」 | AI が1回の実行で、子に出せる依頼の数です | 200 |
| 「1つのタスクで1エージェントへ自動で届く依頼の上限」 | 人の指示なしに、同じ AI へ自動で依頼が届く回数の上限です。0 にすると、自動の依頼をすべて止めます | 20 |
| 「添付ファイル1つの上限（MiB）」 | 添付するファイル1つの大きさの上限です（1〜500）。次の添付から効きます | 50 |
| 「画面のコーディネーターの実行上限（分）」 | 画面のコーディネーターの、1回の実行にかけられる時間です | 30 |
| 「コーディネーターのコマンドの上限（秒）」 | 画面のコーディネーターが実行するコマンド1つにかけられる時間です。責任者と作業者の実行は対象外です | 10 |

タブの下のほうには、次のものがあります。

| 項目 | 意味 | 初めの値 |
| --- | --- | --- |
| 「使用統計データを送信して alpacawork の機能向上に役立てる」 | 使用統計データを開発元に送るかどうかです。このスイッチは、押すとすぐに効きます（[使用統計データ](telemetry.md)） | セットアップで選んだとおり |
| 「読み込んでいるフォルダ」 | データの置き場の場所です。見るだけで、変えられません（[データの場所](manage.md#データの場所)） | `~/alpacawork` |
| 「環境変数ファイル」 | API キーなどを書くファイルの場所と、読み込みの状態（「ファイルなし」「N 件を反映中」「読み込んでいません」）です（[API キーを渡す](projects.md#api-キーを渡す)） | — |

### アプリ・スマホ

設定の項目は無く、3つの案内が出ます。「デスクトップアプリとして使う」は PC にアプリとして入れる手順（[画面を開き直す](manage.md#画面を開き直す)）、「スマホから使う」はスマートフォンから開くまでの手順と QR コード（[スマートフォンで使う](remote.md#スマートフォンで使う)）、「通知を受け取る」は通知の設定を開くボタンです。スマートフォンなど、タッチで操作する端末では、このタブは出ません。

### 端末の状態

alpacawork が動いている PC の「CPU」「メモリの空き」「ディスクの空き」、動いている AI の作業、負荷が厳しかったときの記録（90日分）が出ます。見るだけで、設定の項目はありません。測れるのは Linux だけで、ほかの OS では「Linux で測れます。」と出ます。CPU が 90% 以上（2分続いたとき）、メモリの空きが 10% 未満（1分続いたとき）、ディスクの空きが 50 GB 未満のどれかで、負荷が厳しいと見なします。そのときの通知は、[自分](#自分) の「端末の負荷が厳しいとき」で選びます。

### プロジェクト

設定の「プロジェクト」タブには、すべてのプロジェクトが並びます。アーカイブしたものには「アーカイブ済み」と付きます。行を押すと、そのプロジェクトの設定が開きます。画面の左上のプロジェクト名を押して開くこともできます。変えたあとは「保存」を押します（[プロジェクトの設定を変える](projects.md#プロジェクトの設定を変える)）。

| 項目 | 意味 |
| --- | --- |
| 「名前」 | プロジェクトの名前です |
| 「色」 | 一覧やメニューで、プロジェクトを見分ける色です |
| 「親プロジェクト」 | このプロジェクトを中に持つプロジェクトです。作るときに決め、あとからは変えられません（[プロジェクトを増やす](projects.md#プロジェクトを増やす)） |
| 「作業フォルダ」 | AI が作業するフォルダです。空のままなら、上のプロジェクトの作業フォルダか、データの置き場を使います |
| 「プロジェクト方針」 | このプロジェクトと、中のプロジェクトのすべての AI に、そのまま伝わる約束ごとです（[プロジェクト方針](projects.md#プロジェクト方針)） |
| 「項目」 | AI がタスクに書く項目と、その順番です |
| 「プロジェクトをアーカイブ」 | 中のプロジェクトとタスクごと、一覧から外します。記録、ファイル、コードは残ります（[プロジェクトをアーカイブする・戻す](projects.md#プロジェクトをアーカイブする戻す)） |

### この端末だけに残るもの

次のものは、その端末のブラウザに保存されます。ほかの端末には伝わりません。通知の受け取りの登録も、端末ごとです（[自分](#自分)）。

| 項目 | 意味 | 初めの値 |
| --- | --- | --- |
| 「自動スワイプ」 | あなたの答えを待っているタスクを開くと、入力欄の上に出ます。オンにすると、送信したあと次のタスクへ移ります。オフでは、送信してもそのタスクに留まります（[次のタスクへ進む](guide.md#次のタスクへ進む)） | オフ |
| コーディネーターのモデルとエフォート | 送信ボタンの横で、最後に選んだものを覚えます（[モデルとエフォート](guide.md#モデルとエフォート)） | デフォルトのエージェントと、選べる値の先頭 |
| 一覧の区分の開閉 | 見出しを押して開いた区分と、閉じた区分を覚えます | 「待機中」「保留」「完了」が閉じています |

### 画面に無い設定

| 設定 | 内容 | 変えかた |
| --- | --- | --- |
| AI の返事の言語 | AI があなたに返す言葉と、タスクに書く言葉の言語です。「表示言語」とは別に決まります | 入力欄でコーディネーターに頼みます（[AI の返事の言語](projects.md#ai-の返事の言語)） |
| ポート | 画面の URL の最後の数字です。インストールのときに、空いている番号に決まります | ターミナルで `alpacawork setup --yes --port <番号>` を実行します。終わっていない AI の作業がある間は断られます。変えると、画面の URL も変わります |
| スマートフォンなどから開くための名前 | ほかの端末から開く、HTTPS の入口の名前です。URL から `https://` と末尾の `/` を除いたものです | ターミナルで `alpacawork setup --yes --public-host <名前>` を実行します。別の名前には変えられますが、無しには戻せません（[スマートフォンで使う](remote.md#スマートフォンで使う)） |
| データの置き場 | タスクと記録を置くフォルダです。既定は `~/alpacawork` です | インストールのあとは変えられません（[データの場所](manage.md#データの場所)） |
| API キー | 画面に入れる欄はありません。PC の環境変数ファイル（`~/.config/alpacawork/env`）に自分で書きます | [API キーを渡す](projects.md#api-キーを渡す) |
| 使用統計データの停止 | 画面のスイッチのほかに、コマンドでも止められます | `alpacawork telemetry off`（[送るかどうかを選ぶ・止める](telemetry.md#送るかどうかを選ぶ止める)） |

## キーボードの操作

「⌘/Ctrl」は、Mac では ⌘、ほかでは Ctrl です。「一覧の行で」は、Tab キーなどで一覧の行の題名を選んでいるときのことです。

| キー | 働き |
| --- | --- |
| `/` | 入力欄へ移ります（文字を入力していないとき） |
| Enter、Shift+Enter | PC では、Enter で送信し、Shift+Enter で改行します。スマートフォンなど、タッチで操作する端末では、Enter でも改行します |
| ⌘/Ctrl+Enter | どの端末でも送信します |
| 入力欄で `#`、`/` | `#` はタスクとプロジェクトの候補、`/` はスキルの候補を出します。↑↓ で選び、Tab か Enter で決め、Esc で閉じます |
| ⌘/Ctrl+K | 検索の欄へ移ります |
| ⌘/Ctrl+, | 設定を開きます |
| ⌘/Ctrl+J | タスクを開いているとき、タスクの表示と入力欄の間を行き来します |
| ⌘/Ctrl+0、⌘/Ctrl+1〜9 | 0 はすべてのプロジェクトを表示し、1〜9 はメニューの上から数えた番号のプロジェクトに切り替えます（プロジェクトが2つ以上のとき） |
| Esc | 入力欄から出る、開いたタスクを閉じる、検索を閉じる、の順に働きます |
| H | 開いているタスクを保留にします（文字を入力していないとき） |
| 一覧の行で S、R | S はタスクを開いて入力欄へ移り、R は「状態を変更」を開きます |
| 一覧の行で A、M | A は責任者を決める、または替える欄を開きます（プロジェクトのすぐ下のタスクだけ）。M はタスクを別の親の下へ移す欄を開きます |
| 検索結果で ↑↓ | 前後の行へ移ります |

## コマンドの一覧

ターミナル（Windows では Ubuntu のウィンドウ）で、人が実行するコマンドです。

| コマンド | 働き | 手順 |
| --- | --- | --- |
| `alpacawork setup` | インストールします。入れたあとは、下の `--port` か `--public-host` を付けて設定を変えるときに使います。更新には使いません | [インストールする](getting-started.md#1-インストールする) |
| `alpacawork setup --yes`（`-y`） | 確認を聞かずに進めます | 同じ |
| `alpacawork setup --lang <言語>` | 新しく入れるときの、画面と AI の返事の言語を決めます（例: `--lang ja`） | 同じ |
| `alpacawork setup --no-open` | 終わったあとに、ブラウザを開きません | 同じ |
| `alpacawork setup --workspace <フォルダ>` | 新しく入れるときに、データの置き場を指定します | 同じ |
| `alpacawork setup --port <番号>` | ポートを指定します。入れたあとは、ポートを変えます | [画面に無い設定](#画面に無い設定) |
| `alpacawork setup --public-host <名前>` | ほかの端末から開くための名前を設定します | [画面に無い設定](#画面に無い設定) |
| `alpacawork uninstall` | この PC から alpacawork を外します。データの置き場は残ります | [アンインストールする](manage.md#アンインストールする) |
| `alpacawork workspace url` | 動いている画面の URL を表示します | [画面を開き直す](manage.md#画面を開き直す) |
| `alpacawork deploy npm:alpacawork` | 画面を使わずに、最新の版へ更新します | [画面を使わずに更新する](manage.md#画面を使わずに更新する) |
| `alpacawork skills update` | 同梱のスキル（alpacawork、alpacawork-betterquality）を、今の版で入れ直します。手で書き換えた内容は上書きされます | [スキル](projects.md#スキル) |
| `alpacawork --version` | 入っている版を表示します | — |
| `alpacawork telemetry off` | 使用統計データの送信を止めます | [送るかどうかを選ぶ・止める](telemetry.md#送るかどうかを選ぶ止める) |
| `alpacawork telemetry show` | 使用統計データとして送る内容を表示します | [送る内容を見る](telemetry.md#送る内容を見る) |
| `alpacawork telemetry status` | 使用統計データの今の選択と、この PC の番号を表示します | [送ったデータを削除する](telemetry.md#送ったデータを削除する) |

このほかのコマンド（`alpacawork task`、`alpacawork project`、`alpacawork config` など）は、AI が使うためのものです。
