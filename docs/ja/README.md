# alpacawork のドキュメント

alpacawork は、PC に入っている Claude Code や Codex に仕事を任せる道具です。作業するフォルダをプロジェクトにして依頼を送ると、AI がタスクにして進め、あなたの判断が要るときだけ「確認待ち」に並びます。あなたがするのは、頼む、質問に答える、できあがりを確かめる、の3つです。

## 初めて使う

1. [はじめかた](getting-started.md) — インストールして画面を開き、最初の依頼を送って、できあがりを確かめるまで（15分ほど）
2. [すでにあるリポジトリで使う](projects.md#すでにあるリポジトリで使う)、[プロジェクト方針](projects.md#プロジェクト方針) — 自分の仕事で使い始めるときに決めること
3. [alpacawork の考え方](concept.md) — 1つの依頼がどう進むかと、設計の考え方（あとで読んでもかまいません）

入れる前に確かめておくこと:

- **自分の PC で動くか** → [始める前に](getting-started.md#始める前に)
- **費用** → alpacawork は無料です（MIT License）。AI の利用料は、お使いの Claude Code や Codex などの契約のとおりです
- **AI が何をするか** → AI は確認を求めない設定で動き、作業フォルダのファイルを書き換えられます。してほしくないことは [プロジェクト方針](projects.md#プロジェクト方針) に書きます
- **データの扱い** → [保存されるもの・外へ送られるもの](manage.md#保存されるもの外へ送られるもの)
