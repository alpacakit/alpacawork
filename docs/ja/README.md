# alpacawork のドキュメント

alpacawork は、PC の Claude Code や Codex などの AI エージェントに仕事を任せる道具です。入力欄に依頼を書くと AI がタスクにして進め、あなたの判断が要るときだけ「確認待ち」に並びます。

初めての人は、下の「はじめかた」から読みます。15分ほどで、最初の1件を頼んで確かめるところまで進みます。

## ページ

- [はじめかた](getting-started.md) — 入れて、1件頼んで、確かめるまで
- [使いかた](guide.md) — 頼む、質問に答える、報告を確かめる、保留や中止
- [自分の仕事に合わせる](projects.md) — 既存のリポジトリ、方針、使う AI とモデル
- [スマートフォンと通知](remote.md)
- [困ったとき](troubleshooting.md) — タスクが止まった、画面が開かない
- [開き直す・止める・更新する](manage.md) — URL、更新、アンインストール、データの置き場
- [Claude Code・Codex から使う](chat.md) — 会話からタスクを頼む・確かめる、更新や再起動を頼む
- [言葉とコマンドの一覧](reference.md)
- [alpacawork の考え方](concept.md)
- [使用統計データ](telemetry.md)

使い方で分からないことは、画面の入力欄で AI に聞けます。設定の変更も、たいていは頼めば AI が行います。

## AI エージェントの方へ

インストール・更新・接続などを頼まれたときは、[セットアップの手順書](../../skills/alpacawork/references/setup.md)、うまく動かないときは [Troubleshooting](../../skills/alpacawork/references/troubleshoot.md) を、要約せずに読んで従ってください。
