# How to use it

What you do every day once you have finished Getting started.

## Make a request

Write what you want done in plain words in the input box, and send it. On a PC, Enter sends and Shift+Enter starts a new line.

```text
Find out why the tests are failing, and fix it.
```

What you send goes to the coordinator, the AI you talk to. The coordinator turns it into a task and hands it to an AI that takes it on. You can keep making requests without waiting for earlier ones to finish.

Write how you want the work done in the request, too ("Make 3 options and compare them", "When it's done, have another AI check it"). What you always want goes in the [project policy](projects.md#project-policy).

Attach images or files with the "+" in the input box, or by pasting.

## You can ask for things the screen doesn't have

You can also ask in the input box to change settings, tidy up tasks, restart an AI that stopped, update alpacawork and so on. It's quicker than looking for where to do it on the screen.

```text
Archive all the finished tasks.
```

## Reading the list

Tasks are grouped by state. You act on these two:

| Group | Meaning |
| --- | --- |
| Awaiting review | A question or a report has arrived |
| Needs attention | An AI's run has stopped. Open it to see why |

"In progress" is what the AI is working on, and "Done" is what is finished. "Done" and some others start collapsed; press the heading to open them. The other groups are in [the list of words](reference.md#task-states).

## Answer a question

Open the task to see the question and the options for an answer.

1. Press an option. The answer goes into the input box.
2. Send it. Nothing is delivered until you send.

For an answer that isn't among the options, press "Other" and write it in your own words.

## Check a report

Read the report, and open the attached files or diffs to check them.

- If it is good, press "Done" (the check mark) at the bottom of the screen. The task isn't finished until you press it.
- If you want changes, keep the task open, write them in the input box and send.

Pressing "Done" opens the next task awaiting review. "Change state", for putting a task on hold or stopping it, is in the same place.

## Tasks that stopped

Open a task under "Needs attention" to see why it stopped and the buttons for what to do next.

- Press "Continue with same AI", "Continue with another AI" or "Stop". "Continue with another AI" puts a line in the input box; add which AI to use, then send it.
- If "Continue" appears, press it if it's fine to continue.
- If there are no buttons, follow the message shown and give an instruction in the input box.

What to do for each reason is in [Troubleshooting](troubleshooting.md#a-task-stopped).

## Put on hold or stop

- On hold: For when you don't want to decide now. Open the task, then "Change state" → "On hold" → "Update". An AI that is working doesn't stop.
- Stop: Makes the work stop. "Change state" → "Stopped" → "Update". The tasks under it stop too.

To take a task off hold, choose where it goes back to in the same "Change state". To go on with a stopped task, ask in the input box.

## On a phone

Swipe a card right for "Done" or "Send", and left for "Hold".
