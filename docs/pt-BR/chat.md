# Usar pelo Claude Code ou Codex

Além da caixa de entrada da tela, você pode operar o alpacawork numa conversa do Claude Code ou do Codex aberta no terminal ou no app. Use quando quiser pedir e conferir tarefas na sua conversa de sempre, sem abrir a tela.

## Como começar

No início da conversa, faça um pedido com `/alpacawork` na frente (`$alpacawork` no Codex).

```text
/alpacawork me conte, uma por uma e de forma breve, as tarefas aguardando revisão
```

A IA lê a skill do alpacawork e, a partir daí, a IA dessa conversa atua como o mesmo ponto de contato da caixa de entrada da tela (o coordenador). Do segundo pedido em diante, você pode deixar de lado o `/alpacawork`.

O trabalho que você pede é feito pelas IAs que o alpacawork inicia. Fechar esta conversa não o interrompe.

## Exemplos do que pedir

| Para | Exemplo do que pedir |
| --- | --- |
| Pedir uma tarefa | `crie uma tarefa para corrigir o bug da tela de login e comece` |
| Ver as tarefas aguardando revisão | `me conte, uma por uma e de forma breve, as tarefas aguardando revisão` |
| Perguntar como vão as tarefas | `me diga como vão as tarefas` |
| Encontrar uma tarefa | `encontre a tarefa que corrigiu o README` |
| Responder uma pergunta | `na pergunta da T12, siga com a opção 2` |
| Pedir um ajuste | `deixe o texto do botão na T12 mais curto` |
| Marcar como concluída | `já conferi a T12. Marque como concluída` |
| Adiar ou parar | `adie a T12`, `pare a T12` |
| Criar um projeto | `transforme ~/code/shop num projeto` |

Você pode indicar uma tarefa pelo número (como T12) ou por palavras do título. Os mesmos pedidos funcionam na caixa de entrada da tela (sem `/alpacawork`). Abrir a tela, mudar configurações ou modelos, atualizar e coisas assim estão em ["Operações comuns" no README](../../README.pt-BR.md#operações-comuns).
