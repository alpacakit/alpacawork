# alpacawork documentation

alpacawork is a tool for handing work to Claude Code or Codex on your PC. Write a request in the input box, and the AI turns it into a task and carries it out. A task appears under "Awaiting review" only when it needs your judgment.

If you are new, start with "Getting started" below. In about 15 minutes, you'll have made your first request and checked the result.

## Pages

- [Getting started](getting-started.md) — install, make one request, and check it
- [How to use it](guide.md) — make requests, answer questions, check reports, put on hold or stop
- [Fit it to your work](projects.md) — existing repositories, the policy, which AIs and models to use
- [Phone and notifications](remote.md)
- [Troubleshooting](troubleshooting.md) — a task stopped, the screen doesn't open
- [Reopen, stop and update](manage.md) — the URL, updating, uninstalling, where your data is
- [Use it from Claude Code or Codex](chat.md) — request and check tasks and answer questions from a conversation
- [Words and commands](reference.md)
- [The ideas behind alpacawork](concept.md)
- [Usage data](telemetry.md)

If you are unsure how to do something, ask the AI in the input box. The AI can also change most settings for you if you ask.

## For AI agents

When asked to install, update or connect alpacawork, read and follow the [setup instructions](../skills/alpacawork/references/setup.md) in full, without summarizing; when it doesn't work, do the same with [Troubleshooting](../skills/alpacawork/references/troubleshoot.md).
